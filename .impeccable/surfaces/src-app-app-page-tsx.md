## Direction contract

THESIS: 메인 대시보드는 "고요한 경영 브리핑 문서"에서 "능동적인 관제 콘솔"로 전환한다 — 사용자가 열자마자
"이 도구는 지금 살아있고 내가 조작할 수 있다"고 느끼게 한다. 이 카테고리의 기본값(same-size 아이콘 카드
그리드를 그대로 늘어놓는 SaaS 템플릿)은 거부하지 않는다 — 사용자가 핀한 레퍼런스가 정확히 그 패턴이므로
브리핑이 이겼던 이전 결정 대신 이 패턴을 그대로 받아들인다.

OWN-WORLD: 좌측 고정 다크 사이드바(oklch 0.16 근처 무채색에 가까운 다크, 아주 미세한 청색조) + 우측
라이트 콘텐츠 영역. 브랜드 액센트는 네온 라임(oklch(0.87 0.19 125) 부근, 매우 밝고 채도 높은 옐로우그린)
— 사이드바 활성 항목 필, 주요 버튼, 차트 강조선, 카드 아이콘 배경에 전용. 기존 위험(빨강)/주의(주황)/정상
(녹색)/정체(회색) 4색 신호 체계는 절대 재해석하지 않고 그대로 보존 — 네온 라임은 그 4색과 색상환에서
확실히 분리된 옐로우그린이라 혼동되지 않는다. 카드는 흰 배경 + 얇은 보더 + 12px 라운드, 하나의 "히어로"
카드만 다크 채움. 타이포는 기존 Noto Sans KR 유지(한국어 UI, 폰트 교체 불필요).

STORY: 의사결정권자가 사이드바에서 현재 위치(대시보드)를 한눈에 인지하고, 상단 히어로+통계 카드 행에서
오�늘의 핵심 수치를 스캔하고, 게이지/도넛 차트에서 위험 분포를 보고, 필 태그로 빠르게 필터링해 전체
재고 테이블로 내려간다 — 기존 "브리핑 → 근거 → 상세" 탐색 순서는 그대로, 표현 방식만 다크 사이드바 +
카드 그리드로 바뀐다.

FIRST VIEWPORT: 좌측 폭 240px 다크 사이드바(로고, 대시보드/업로드/게시판/설정 네비, 하단 로그아웃) +
우측 상단 헤더(페이지 타이틀, 날짜 조회 컨트롤, 네온 라임 "적용" 버튼) + 통계 카드 4~5개 행(다크 히어로
1개 + 화이트 카드 나머지, 아이콘·증감 뱃지) + 그 아래 차트 2열(도넛/게이지 재고위험분포, TOP7 소진량 막대) +
필 태그 빠른 필터 행 + 전체 재고 테이블.

FORM: 사용자가 직접 첨부한 레퍼런스 스크린샷("Vault" 재고관리 대시보드 템플릿)을 핀된 시각 세계로 채택 —
별도의 7종 후보 탐색/주사위 라운드 없이 이 레퍼런스를 그대로 build 대상으로 삼는다. seed key: N/A(pinned
reference, no concept-seed roll).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict,
DESIGN.md, and every shipping raster carrying its provenance.
